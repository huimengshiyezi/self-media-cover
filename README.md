# 公众号封面配图工具

一个面向公众号作者的轻量封面配图工具。固定 21:9 画板，自带默认背景与得意黑标题字体，零依赖、双击即用，无需登录、无需联网。

## 特性

- **固定 21:9 画板**（1800 × 766），与公众号封面比例一致
- **默认背景图**，开箱即用；可一键上传替换
- **主标题字体固定**：得意黑 Regular（Smiley Sans v2.0.1），本地嵌入
- **文字属性全套**：字号 / 字间距 / 行间距 / 对齐 / 字色 / 描边 / 阴影（含偏移、模糊、不透明度）/ 位置 / 最大宽度（自动换行）
- **对齐相对画布绝对锚定**：左对齐贴边、居中相对画布中心、右对齐贴右边
- **水印锁定机制**：「AI 绘梦师葉子」默认锁定在 (70, 700)，加粗版阿里普惠体；支持改文字、改字号字色透明度；关闭锁定后可调 X/Y 偏移，便于换账号使用
- **模板导出/导入**：当前所有设置存为 JSON，下次导入即恢复
- **导出 PNG / JPG**（95% 质量）
- **完全本地化**：字体嵌入 woff2，无需联网

## 使用方式

### 方式 A：直接双击打开（推荐）

下载/克隆本项目后，双击 `index.html`，浏览器自动打开工具即可使用。

### 方式 B：本地起静态服务（可选，更稳）

部分浏览器对 `file://` 协议下的字体加载有 CORS 限制，若发现字体未生效，可起一个简单 HTTP 服务：

```bash
# Python
python -m http.server 8000

# 或 Node
npx serve .
```

然后浏览器访问 `http://localhost:8000`。

## 默认参数

| 类别 | 项 | 默认值 |
|---|---|---|
| 标题 | 文本 | 你的公众号标题 |
| 标题 | 字号 / 字间距 / 行间距 | 120 / 0 / 1.4 |
| 标题 | 位置 X 偏移 / Y 偏移 | 50 / 200 |
| 标题 | 最大宽度 | 1800 |
| 描边 | 默认关闭，开启后宽度 | 3 |
| 阴影 | 默认关闭，开启后 X/Y/模糊 | 7 / 7 / 9 |
| 阴影 | 不透明度 | 70 |
| 水印 | 文本 | AI 绘梦师葉子 |
| 水印 | 字号 / 不透明度 | 50 / 80 |
| 水印 | 锁定坐标 | (70, 700) |

## 工作流

1. 打开工具，默认背景已加载
2. 输入主标题文字（默认"你的公众号标题"占位）
3. 调整字号、字间距、对齐、颜色、描边、阴影等
4. 必要时上传替换背景图
5. 满意后导出 PNG 或 JPG 下载到本地
6. 想保存当前样式下次复用？点「保存模板」导出 JSON，下次「加载模板」导入即可

## 已知限制

- 文字位置仅滑块调整，暂不支持鼠标拖拽
- 单文字图层，暂不支持多标题
- 导出分辨率固定 1800 × 766，无超采样
- 字体首次加载约 1~2 秒（5MB woff2）
- 默认背景图为内置样图，可自由替换
