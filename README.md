# 自媒体封面工具

一个面向自媒体作者的轻量封面配图工具。默认 21:9 画板，自带默认背景与得意黑标题字体，零依赖、双击即用，无需登录、无需联网。

## 特性

- **画布尺寸预设**（默认自媒体封面 1800 × 766，21:9），换尺寸后画布、位置滑块范围、水印锁定位置、背景铺满方式全部自适应
- **默认背景图**，开箱即用；可一键上传替换（按当前画布等比铺满 + 居中裁切，不拉伸变形）
- **主标题字体固定**：得意黑 Regular（Smiley Sans v2.0.1），本地嵌入
- **文字属性全套**：字号 / 字间距 / 行间距 / 对齐 / 字色 / 描边 / 阴影（含偏移、模糊、不透明度）/ 位置 / 最大宽度（自动换行）
- **对齐相对画布绝对锚定**：左对齐贴边、居中相对画布中心、右对齐贴右边
- **水印锁定机制**：「AI 绘梦师葉子」默认锁定在画布左下角（默认尺寸下是 (70, 700)），加粗版阿里普惠体；支持改文字、改字号字色透明度；关闭锁定后可调 X/Y 偏移，便于换账号使用
- **模板导出/导入**：当前所有设置（含画布尺寸预设与宽高）存为 JSON，下次导入即恢复
- **导出 PNG / JPG**（95% 质量），导出尺寸 = 当前画布尺寸
- **完全本地化**：字体嵌入 woff2，无需联网

## 画布尺寸预设

| 预设 | 尺寸 |
|---|---|
| 自媒体封面 21:9（默认） | 1800 × 766 |
| 自媒体首图 2.35:1 | 900 × 383 |
| 自媒体方图 1:1 | 900 × 900 |
| 正文配图 16:9 | 1280 × 720 |
| 小红书竖图 3:4 | 1080 × 1440 |
| 抖音竖版 9:16 | 1080 × 1920 |
| 自定义 | 自己填宽 × 高（240 ~ 6000） |

> ⚠️ 以上尺寸是各平台的**常见值**，不保证与平台后台当前要求一致，**请以平台后台为准**。

切换预设时自动跟着变的东西：

1. `<canvas>` 的像素尺寸与显示缩放
2. 位置区块 X / Y 偏移、最大宽度三个滑块的取值范围
3. 水印锁定位置（左右边距按宽度等比、下边距固定 66px，随画布重算）
4. 标题位置与字号按新画布等比缩放，并夹回画面内（不会跑到画布外看不见）
5. 背景图按新画布 cover（等比铺满 + 居中裁切）
6. 导出 PNG / JPG 的分辨率

## 使用方式

### 方式 A：直接双击打开（推荐）

下载/克隆本项目后，双击 `index.html`，浏览器自动打开工具即可使用。

### 方式 B：本地起静态服务（可选，更稳）

部分浏览器对 `file://` 协议下的字体加载有 CORS 限制，若发现字体未生效，可起一个简单 HTTP 服务：

```bash
# Python
python -m http.server 8000

# 或 Node
npx serve .
```

然后浏览器访问 `http://localhost:8000`。

## 工作流

1. 打开工具，默认背景已加载（默认画布 1800 × 766）
2. 先选画布尺寸预设（要做竖图 / 方图就在这里切换，或选「自定义」填宽高）
3. 输入主标题文字（默认"你的自媒体标题"占位）
4. 调整字号、字间距、对齐、颜色、描边、阴影等
5. 必要时上传替换背景图
6. 满意后导出 PNG 或 JPG 下载到本地（分辨率 = 当前画布尺寸）
7. 想保存当前样式下次复用？点「保存模板」导出 JSON，下次「加载模板」导入即可（画布尺寸一起还原）

## 已知限制

- 文字位置仅滑块调整，暂不支持鼠标拖拽
- 单文字图层，暂不支持多标题
- 导出分辨率 = 当前画布尺寸，无超采样
- 换画布预设时，标题的字号与位置按比例缩放后夹回画面内 —— 如果你已经精调过位置，换预设后需要再看一眼
- 平台预设尺寸为常见值，可能与平台后台的当前要求不一致（以平台后台为准）
- 字体首次加载约 1~2 秒（5MB woff2）
- 默认背景图为内置样图，可自由替换
